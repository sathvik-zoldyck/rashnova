<a name="why"></a>
## എന്തുകൊണ്ട് Rashnova

വിമാനങ്ങളിലും ട്രെയിനുകളിലും കപ്പലുകളിലും ബ്ലാക്ക് ബോക്സുണ്ട്. നിങ്ങളുടെ കൈയിൽ നിന്ന് പോകുന്ന കമ്പ്യൂട്ടറിൽ ഒന്നുമില്ല,
അത് കൈവശമുള്ള വ്യക്തിക്ക് അതിലുള്ള എല്ലാറ്റിലേക്കും പൂർണ്ണ പ്രവേശനമുണ്ട്.

ആ പ്രവേശനം ഉപയോഗിക്കപ്പെടുന്നു. [University of Guelph-ലെ ഗവേഷകരുടെ 2022-ലെ ഒരു പഠനത്തിൽ](https://arxiv.org/abs/2211.05824)
(IEEE Symposium on Security and Privacy 2023-ൽ പ്രസിദ്ധീകരിച്ചത്), ലോഗിംഗ് ഓണാക്കിയ ലാപ്‌ടോപ്പുകൾ 12 റിപ്പയർ ഷോപ്പുകളിൽ
രാത്രി മുഴുവൻ വെച്ചു. അവയിൽ ആറിടത്തെ ടെക്നീഷ്യൻമാർ അവയിലെ വ്യക്തിഗത ഡാറ്റ തുറന്നുനോക്കി, രണ്ടിടത്തുള്ളവർ ലാപ്‌ടോപ്പിൽ
നിന്ന് ഡാറ്റ പകർത്തിയെടുത്തു. ആന്റിവൈറസും എൻഡ്‌പോയിന്റ് ടൂളുകളും ഇത് ശ്രദ്ധിക്കാനായി നിർമ്മിച്ചവയല്ല: ആ വ്യക്തിക്ക്
താക്കോൽ നേരിട്ട് നൽകിയതാണ്.

Rashnova പ്രതിരോധമല്ല. ഇത് തെളിവാണ്, സംഭവിച്ചത് തർക്കത്തിലൂടെയല്ല, പരിശോധനയിലൂടെ അറിയാൻ.

> *വിശ്വാസം നല്ലതാണ്. തെളിവ് അതിലും നല്ലത്.*

<a name="never"></a>
## ഇത് ഒരിക്കലും രേഖപ്പെടുത്താത്തത്

എന്തോ സംഭവിച്ചു **എന്നത്** ആണ് Rashnova രേഖപ്പെടുത്തുന്നത്, സ്ക്രീനിൽ എന്തായിരുന്നു എന്നതല്ല. ഇത് രേഖപ്പെടുത്താത്തവ:

- കീസ്ട്രോക്കുകൾ
- ക്ലിപ്പ്ബോർഡിലെ ഉള്ളടക്കം
- നിങ്ങളുടെ സ്ക്രീൻ, ചിത്രമായോ വീഡിയോ ആയോ
- നിങ്ങളുടെ ക്യാമറയോ മൈക്രോഫോണോ
- നിങ്ങളുടെ ഡോക്യുമെന്റുകൾ, ഫോട്ടോകൾ, ഇമെയിലുകൾ, സന്ദേശങ്ങൾ എന്നിവയുടെ ഉള്ളടക്കം
- നിങ്ങൾ സന്ദർശിക്കുന്ന വെബ് പേജുകളോ അവയിലുള്ളതോ

ഇത് രേഖപ്പെടുത്തുന്ന രണ്ട് കാര്യങ്ങൾ അറിഞ്ഞിരിക്കുന്നത് നല്ലതാണ്. Repair session സമയത്ത് PowerShell കമാൻഡുകൾ
പ്രവർത്തിക്കുമ്പോൾ രേഖപ്പെടുത്തുന്നു, ഒരാൾ ആരംഭിക്കുന്ന ഓരോ പ്രോഗ്രാമിന്റെയും പൂർണ്ണ സ്റ്റാർട്ട്-അപ്പ് ലൈനും; അതിനാൽ ഒരു
ലിങ്കിൽ നിന്ന് തുറന്ന ബ്രൗസർ ആ ലിങ്ക് കാണിക്കുന്നു.

ഉദാഹരണത്തിന്, `Bank_Statement_Aug2026.pdf` എന്നത് `Documents\Finance`-ൽ നിന്ന് Microsoft Edge 15:01:16-ന്
തുറന്നു എന്ന് റിപ്പോർട്ട് പറയുന്നു. സ്റ്റേറ്റ്മെന്റിൽ എന്തായിരുന്നു എന്ന് പറയുന്നില്ല.

<a name="how"></a>
## ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

1. **ഇൻസ്റ്റാൾ ചെയ്യുക.** Setup, Rashnova-യും അതിന്റെ പശ്ചാത്തല റെക്കോർഡറും ഇൻസ്റ്റാൾ ചെയ്യുന്നു.
2. **ഒരു PIN സജ്ജമാക്കുക.** PIN പരിശോധിക്കുന്നത് റെക്കോർഡറാണ്, ആപ്പ് വിൻഡോയല്ല.
3. **ഏൽപ്പിക്കുന്നതിന് മുമ്പ്:** **Repair Mode > Activate**, തുടർന്ന് നിങ്ങളുടെ PIN.
4. **ഏൽപ്പിക്കുക.** "ഇത് എന്ത് ചെയ്യുന്നു" എന്നതിലെ എല്ലാം സീൽ ചെയ്ത രേഖയിലേക്ക് എഴുതപ്പെടുന്നു.
5. **തിരികെ ലഭിക്കുമ്പോൾ:** **Deactivate**, തുടർന്ന് നിങ്ങളുടെ PIN. നിങ്ങൾക്ക് വിധിയും റിപ്പോർട്ടും ചെയിൻ പരിശോധനയും ലഭിക്കും.

റെക്കോർഡർ ഒരു Windows സേവനമായി പ്രവർത്തിക്കുന്നു, അതിനാൽ ആരെങ്കിലും Rashnova വിൻഡോ തുറന്നാലും ഇല്ലെങ്കിലും
റെക്കോർഡിംഗ് തുടരുന്നു, റീസ്റ്റാർട്ടിന് ശേഷം അത് സ്വയം വീണ്ടും ആരംഭിക്കുന്നു.

**ഓരോ സെഷനും നാല് വിധികളിൽ ഒന്നോടെ അവസാനിക്കുന്നു:**

| വിധി | അർത്ഥം |
| --- | --- |
| **Quiet** | രേഖ പരിശോധിച്ചുറപ്പിച്ചതാണ്, പൂർണ്ണമാണ്, ഉയർന്ന പ്രാധാന്യമുള്ളതൊന്നും സംഭവിച്ചില്ല. |
| **Notable** | കുറഞ്ഞത് ഒരു ഉയർന്ന (high) അല്ലെങ്കിൽ ഗുരുതരമായ (critical) സംഭവം: വായിക്കേണ്ടതാണ്. |
| **Compromised** | സെഷനുള്ളിൽ രേഖയിൽ ഒരു വിടവുണ്ട് (കമ്പ്യൂട്ടർ ഓഫായിരുന്നു, സ്ലീപ്പിലായിരുന്നു, റീസ്റ്റാർട്ട് ചെയ്യുകയായിരുന്നു, അല്ലെങ്കിൽ നിരീക്ഷണം തടസ്സപ്പെട്ടു) അല്ലെങ്കിൽ ഇടപെടൽ കാണുന്നു, അതിനാൽ മുഴുവൻ സെഷനും ഇതിന് ഉറപ്പ് നൽകാനാവില്ല. |
| **Chain broken** | രേഖ പരിശോധനയിൽ വിജയിക്കുന്നില്ല. എല്ലാം ഇപ്പോഴും കാണിക്കുന്നു, പരിശോധിക്കാത്തത് എന്ന് അടയാളപ്പെടുത്തി. |

   ```powershell
   Get-FileHash "$env:USERPROFILE\Downloads\Rashnova-Setup-1.1.0.exe"
   ```
   ഹാഷ്, `SHA256SUMS.txt`-ലെയും റിലീസ് കുറിപ്പുകളിലെയും ഹാഷുമായി കൃത്യമായി പൊരുത്തപ്പെടണം.

   കാണിക്കും, കാരണം ഇൻസ്റ്റാളറിന് ഇതുവരെ കോഡ്-സൈനിംഗ് ഇല്ല ([അറിയപ്പെടുന്ന പരിമിതികൾ](KNOWN_LIMITS.md) കാണുക).
   **More info** തിരഞ്ഞെടുക്കുക, തുടർന്ന് **Run anyway**.
4. [ലൈസൻസ് നിബന്ധനകൾ](https://www.alcyonesecure.com/terms) അംഗീകരിച്ച്, ഇൻസ്റ്റാൾ ചെയ്ത്, Rashnova തുറക്കുക.
5. ഒരു PIN സജ്ജമാക്കി, സെഷൻ-മാത്രം റെക്കോർഡിംഗ് (ഡിഫോൾട്ട്) നിലനിർത്തണോ എപ്പോഴും-ഓൺ റെക്കോർഡിംഗ് ഓണാക്കണോ എന്ന് തിരഞ്ഞെടുക്കുക.

<a name="limits"></a>
## അറിയപ്പെടുന്ന പരിമിതികൾ

Rashnova എന്ത് ചെയ്യുന്നില്ല എന്ന് ഞങ്ങൾ പ്രസിദ്ധീകരിക്കുന്നു, വസ്തുതകളുടെ അടിസ്ഥാനത്തിൽ നിങ്ങൾക്ക് തീരുമാനിക്കാൻ. ഏറ്റവും പ്രധാനപ്പെട്ടവ:

- **കമ്പ്യൂട്ടർ ഓഫായിരിക്കുമ്പോഴോ സ്ലീപ്പിലായിരിക്കുമ്പോഴോ റീസ്റ്റാർട്ട് ചെയ്യുമ്പോഴോ ഒന്നും രേഖപ്പെടുത്താനാവില്ല.** സെഷൻ
  തുടരുന്നു, ഓരോ തടസ്സവും അതിന്റെ ദൈർഘ്യവും റിപ്പോർട്ട് കാണിക്കുന്നു.
- **അഡ്മിനിസ്ട്രേറ്റർമാർക്ക് രേഖ വായിക്കാം.** ഒരു പ്രോഗ്രാമിനും അതിന്റെ ഫയലുകൾ Windows അഡ്മിനിസ്ട്രേറ്ററിൽ നിന്ന് മറയ്ക്കാനാവില്ല.
- **ഇൻസ്റ്റാളറിന് ഇതുവരെ കോഡ്-സൈനിംഗ് ഇല്ല,** അതിനാൽ പ്രവർത്തിക്കുന്നതിന് മുമ്പ് Windows SmartScreen മുന്നറിയിപ്പ് നൽകുന്നു.
- **USB സ്റ്റോറേജ് തടയൽ 1.1.0-ൽ ഇല്ല.** ഓരോ USB ഡ്രൈവും അതിലേക്ക് പകർത്തിയ ഓരോ ഫയലും രേഖപ്പെടുത്തുന്നു; തടയൽ ഒരു
  അപ്ഡേറ്റിൽ വരും.

ഓരോന്നിന്റെയും കാരണവും പദ്ധതിയും സഹിതം പൂർണ്ണ പട്ടിക (ഇംഗ്ലീഷിൽ): **[KNOWN_LIMITS.md](KNOWN_LIMITS.md)**.
